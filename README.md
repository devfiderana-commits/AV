# Video Call App

React + Vite + TailwindCSS + Supabase + WebRTC.

## Installation

1. Copier `.env.example` en `.env`
2. Ajouter `VITE_SUPABASE_URL` et `VITE_SUPABASE_ANON_KEY`
3. Installer les dépendances:

```bash
npm install
```

4. Lancer le projet:

```bash
npm run dev
```

## Structure

- `src/lib/supabase.js` : client Supabase
- `src/pages/Login.jsx` : formulaire d’authentification
- `src/pages/Dashboard.jsx` : tableau de bord utilisateur
- `src/pages/CallRoom.jsx` : prototype WebRTC + Supabase signalisation
- `src/components/VideoPlayer.jsx` : affichage vidéo
- `src/components/CallControls.jsx` : boutons d’appel
- `src/components/UserList.jsx` : liste d’utilisateurs

## Supabase

Créer la table `signals` dans votre projet Supabase :

```sql
create table signals (
  id bigint generated by default as identity primary key,
  type text,
  data jsonb,
  created_at timestamp with time zone default timezone('utc', now())
);
```

## Notes

- Le signalement WebRTC passe par Supabase Realtime.
- Le code est un MVP de l’appel 1v1 et doit être testé avec deux clients.
